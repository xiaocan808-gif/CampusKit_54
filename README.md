## 📖 项目简介

CampusKit_54 是一个面向大学生的**轻量级校园实用工具集**，采用 Python 开发，集成了 GPA 计算器、课程表管理、学期倒计时等常用功能。

项目旨在通过开源的方式，帮助同学们更高效地管理学业与生活，同时提供一个学习和实践开源文化的平台。

## ✨ 功能特性

### 🧮 GPA 计算器
- 支持**四分制**和**五分制**两种计算模式
- 自动计算加权平均分
- 支持自定义学分权重
- 输出详细的单科成绩明细

### 📅 课程表管理
- 添加、查询、修改课程信息
- 支持按星期查看
- 本地 SQLite 数据库存储，数据安全

### ⏰ 学期倒计时
- 追踪重要日期（考试、作业截止、假期等）
- 显示剩余天数
- 支持多个倒计时事件

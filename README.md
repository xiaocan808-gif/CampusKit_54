[!0](https://opensource.org/licenses/MIT)
[!1](https://www.python.org/)

## 简介

CampusKit_54 是一个面向大学生的轻量级校园实用工具集，提供 GPA 计算、课程表管理、学期倒计时等功能，帮助学生高效管理学业与生活。

## 功能特性

- **GPA 计算器** - 支持四分制/五分制，自动计算加权平均分
- **课程表管理** - 添加、查询、修改课程信息，支持按周查看
- **学期倒计时** - 追踪重要日期（考试、作业截止、假期等）
